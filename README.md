# Data Lab — Banco de Dados

Apresentação híbrida em React para os cinco cadernos de prática de Banco de Dados. Inclui modo de apresentação e modo de exploração.

## Requisitos
- Node.js 20.19+ (ou versão compatível com Vite)
- npm

## Executar localmente
```bash
npm install
npm run dev
```
Abra o endereço local indicado pelo Vite.

## Gerar versão de produção
```bash
npm run build
npm run preview
```

## Controles
- **→**, **Espaço** ou **Page Down**: próximo capítulo
- **←** ou **Page Up**: capítulo anterior
- **H**: abrir ajuda de navegação
- **Esc**: fechar janelas
- Botão de tela cheia: ativar/desativar tela cheia do navegador

## Modos
- **Apresentação:** fluxo visual, evidências e ideia-chave em foco.
- **Exploração:** inclui explicações detalhadas e glossário expansível.

## Conteúdo e fidelidade
Os capítulos 1, 3, 4 e 5 foram estruturados a partir dos cadernos legíveis nesta conversa. O PDF do Caderno 2 não pôde ser extraído com confiabilidade; a seção correspondente está identificada com essa limitação e não inventa resultados numéricos. Revise os detalhes do Caderno 2 com o PDF original antes de uma entrega avaliativa.

## Personalização
Edite `src/data.js` para atualizar títulos, conceitos, evidências e explicações. A apresentação utiliza CSS próprio e ícones `lucide-react`; os diagramas principais são construídos com HTML e CSS, sem imagens pesadas.
